## Consequences for a reusable skill

Use chronology plus scoped authority, separate imported claims from primary evidence,
require actual per-file review declarations, preserve stable IDs and partial test
obligations, verify concrete field types and wire names, inventory operation AND
variant coverage, and keep sensitive list fetches distinct from visible columns.

Do not hardcode the source run's entities, numbers, models, issue IDs, timestamps or
page limits into generic defaults. The source-run packet remains outside the installed
skill directory; this distilled note is optional context, not a verified snapshot.
